# Human Activity Recognition using Machine Learning

## Project Overview
This project focuses on recognizing different human activities using sensor data and machine learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Steps
- Data Loading
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Feature Analysis
- Model Training
- Model Evaluation
- Activity Prediction

## Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest

## Results
The trained machine learning models were evaluated using accuracy, classification reports, and confusion matrices.

## Conclusion
This project demonstrates how machine learning can be used to analyze sensor data and recognize different human activities.
